# 동국대학교 e-Class 다크 테마

## 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 폴더(`dongguk-eclass-dark-mode`)를 선택합니다.
5. `https://eclass.dongguk.edu/`를 열거나 새로고침합니다.

확장 프로그램 아이콘을 누르면 다크 테마를 즉시 켜거나 끌 수 있습니다.
선택한 상태는 Chrome에 저장되어 다음 방문에도 유지됩니다. 처음 설치했을 때는 켜진 상태가 기본값입니다.

## CSS 수정

화면 색상은 `dark.css`만 수정하면 됩니다. 수정한 뒤 `chrome://extensions`에서 확장의 새로고침 버튼을 누르고 e-Class 페이지를 새로고침하세요.

다른 동작 파일은 건드릴 필요가 없습니다.
